# معماری فنی مغز دوم (Architecture)

## ۱. پشته فناوری (Tech Stack)
- **فریم‌ورک و ابزارها:** React 18 + TypeScript + Vite + Tailwind CSS
- **پایگاه‌داده محلی:** Dexie.js (IndexedDB) - ۱۰۰٪ آفلاین و Local-first
- **تقویم شمسی:** `jalaali-js` برای محاسبات تقویم ایران و روزهای هفته
- **آیکون‌ها:** `@remixicon/react` یکپارچه

## ۲. الگوهای طراحی و ماژول‌ها
- **Repository Pattern:** لایه UI تنها با اینترفیس‌های ریپازیتوری در ارتباط است (`taskRepo`, `noteRepo`, `eventRepo`, `tagRepo`, `entryRepo`).
- **چرخه حیات نرم (Soft Lifecycle):** عدم حذف فیزیکی؛ وضعیت‌های مجاز: `open`، `done`، `dropped`، `migrated`.
- **سیستم توست سبک (Toast Pub-Sub):** ماژول ساده رویدادمحور در `src/lib/toast.ts` برای نمایش توست‌های سیستمی بدون وابستگی خارجی.
- **سنجاق‌کردن (Pinning Logic):** آیتم‌های پین‌شده به صورت خودکار از جریان روز فیلتر شده و در کانتینر اختصاصی بالای استریم روز نمایش داده می‌شوند.
- **پایداری تنظیمات:** ذخیره‌سازی والپیپر و تنظیمات در `localStorage`.
