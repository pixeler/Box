# بازطراحی نسخه دسکتاپ (Desktop Redesign)

> سند پیگیری. هر کاری که انجام می‌شود تیک می‌خورد تا بعداً بتوان از همان‌جا ادامه داد.
> الهام: لیاوت Wafer — قاب هماهنگ با تم که دور «بوم» (canvas) را گرفته، بوم با پس‌زمینه ابر و آسمان داینامیک و گوشه‌های گرد، پنجره‌ی اصلی شناور وسط بوم، و دکمه‌ی سرچ شیشه‌ای در گوشه.

## اصول
- فقط روی **دسکتاپ (عرض ≥ 1024px)** اعمال می‌شود. موبایل و تبلت همان `BottomDock` قبلی را دارند.
- در فاز ۱ **پنجره‌ها (امروز / تقویم / یادداشت) بازطراحی نمی‌شوند**؛ فقط ناوبری و لیاوت کلی.
- جهت RTL: ساید‌بار سمت **راست**، سرچ در گوشه‌ی **بالا-چپ** بوم (گوشه‌ی مقابل ساید‌بار).

## ساختار لیاوت دسکتاپ
```
┌──────────────────────────────────────────────┐  ← قاب هماهنگ با تم (رنگ ساید‌بار)، تمام صفحه
│ ┌──────────────────────────────┐ ┌─────────┐ │
│ │ (سرچ شیشه‌ای)                 │ │ لوگو  ⇤ │ │
│ │                              │ │ امروز   │ │
│ │        ┌────────────┐        │ │ تقویم   │ │
│ │        │ پنجره شناور │        │ │ یادداشت │ │
│ │        └────────────┘        │ │         │ │
│ │   بوم با والپیپر، گوشه گرد    │ │ پروفایل │ │
│ └──────────────────────────────┘ └─────────┘ │
└──────────────────────────────────────────────┘
```
